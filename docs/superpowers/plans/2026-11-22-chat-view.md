# Chat view Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** An agent pane (Claude, Codex, omp) can switch between Terminal and Chat; Chat shows the transcript as messages, tool rows with arguments and results, thinking, a plan card, a pending question card and a subagent tray, over the pane's docked composer.

**Architecture:** `mkrew_core::thread::ThreadReader` grows additive fields (call id, input, result, thinking, plan, question, subagents) and takes its turn limit as an argument.
The UI reads each transcript once per session through a shared per-session reader (`Shell::reads`) used by the session panel's Thread section and by every pane in Chat mode.
The mode is a per-pane flag on the layout leaf (`Node::Pane { chat: Option<bool> }`), saved with `tab.set_layout`, so the daemon (which stores the layout as opaque JSON) and older layouts need no change.
The Chat page is a pure view model (`mkrew_ui::chat`) drawn by `shell/chat_view.rs`; the terminal entity keeps running underneath, it is just not drawn.

**Tech Stack:** Rust, GPUI (gpui-pre 0.3.7 pinned by the workspace), serde_json, insta not needed.

**Spec:** `docs/superpowers/specs/2026-11-22-chat-view-design.md` (commit ad29d9a).
Read it fully before starting; this plan argues from it.
Where the code contradicts the spec, the "Spec gaps" list at the end records the conservative choice made here.

## Review Focus

Input classes the spec implies but a happy-path test would miss, most likely first; each has its test in the named task.

5. A text selection kept across a page refresh that dropped, shortened or replaced its message (stale selection): it is ignored, never a panic and never copying another message (Task 10 tests).

    fn tool(name: &str, target: &str) -> ToolCall {
        ToolCall {
            id: String::new(),
            name: name.into(),
            target: target.into(),
            input: String::new(),
            result: None,
        }
    }

    fn text(t: &str) -> Item {
        Item::Text(t.into())
    }

    fn turn(prompt: &str, items: Vec<Item>) -> Turn {
        Turn {
            prompt: prompt.into(),
            items,
            ..Turn::default()
        }
    }

    fn read(format: UsageFormat, bytes: &[u8]) -> ThreadReader {
        let mut reader = ThreadReader::new(&format, THREAD_TURNS).unwrap();
        reader.feed(bytes);
        reader
    }

    /// The turns as the first version of the reader gave them: no thinking, no call details.
    fn plain(reader: &ThreadReader) -> Vec<Turn> {
        reader
            .turns()
            .iter()
            .map(|t| {
                let items = t.items.iter().filter_map(|item| match item {
                    Item::Thinking(_) => None,
                    Item::Text(text) => Some(Item::Text(text.clone())),
                    Item::Tools(calls) => Some(Item::Tools(
                        calls.iter().map(|c| tool(&c.name, &c.target)).collect(),
                    )),
                });
                turn(&t.prompt, items.collect())
            })
            .collect()
    }

    /// Every call of the turn, in order.
    fn calls(turn: &Turn) -> Vec<&ToolCall> {
        turn.items
            .iter()
            .filter_map(|item| match item {
                Item::Tools(calls) => Some(calls.iter()),
                _ => None,
            })
            .flatten()
            .collect()
    }

    fn prompts(count: usize) -> Vec<u8> {
        let mut bytes = Vec::new();
        for i in 0..count {
            bytes.extend_from_slice(
                format!(
                    "{{\"type\":\"message\",\"message\":{{\"role\":\"user\",\"content\":[{{\"type\":\"text\",\"text\":\"p{i}\"}}]}}}}\n"
                )
                .as_bytes(),
            );
        }
        bytes
    }

impl Turn {
    /// Fills the call `id` of this turn with `result`; false (nothing changes) when the turn
    /// has no such call.
    fn set_result(&mut self, id: &str, result: ToolResult) -> bool {
        if id.is_empty() {
            return false;
        }
        for item in self.items.iter_mut().rev() {
            if let Item::Tools(calls) = item
                && let Some(call) = calls.iter_mut().rev().find(|call| call.id == id)
            {
                call.result = Some(result);
                return true;
            }
        }
        false
    }
}

/// `text` cut to at most `max` bytes on a char boundary, with [`CUT`] after a cut.
fn clip(text: &str, max: usize) -> String {
    if text.len() <= max {
        return text.to_owned();
    }
    let end = (0..=max)
        .rev()
        .find(|&at| text.is_char_boundary(at))
        .unwrap_or(0);
    format!("{}{CUT}", &text[..end])
}

    Line::Tool(ToolCall {
        id: id.as_str().unwrap_or_default().to_owned(),
        name: name.as_str().unwrap_or_default().to_owned(),

        input: input_text(input),

/// The arguments as shown: pretty JSON, or the raw text of a patch; cut.
fn input_text(input: &Value) -> String {
    match input {
        Value::Null => String::new(),
        Value::String(text) => clip(text, INPUT_MAX),
        other => clip(
            &serde_json::to_string_pretty(other).unwrap_or_default(),
            INPUT_MAX,
        ),
    }
}

fn thinking(block: &Value) -> Option<Line> {
    let text = block["thinking"].as_str()?.trim();
    (!text.is_empty()).then(|| Line::Thinking(clip(text, THINKING_MAX)))
}

fn result(id: &Value, text: &str, is_error: bool) -> Line {
    Line::Result {
        id: id.as_str().unwrap_or_default().to_owned(),
        result: ToolResult {
            text: clip(text.trim_end(), RESULT_MAX),
            is_error,
        },
    }
}

/// A result's `content`: a string, or the `text` of its blocks joined by newlines.
fn result_text(content: &Value) -> String {
    match content {
        Value::String(text) => text.clone(),
        Value::Array(blocks) => blocks
            .iter()
            .filter_map(|block| block["text"].as_str())
            .collect::<Vec<_>>()
            .join("\n"),
        _ => String::new(),
    }
}

/// A Codex tool output: plain text, or a JSON string `{"output", "metadata": {"exit_code"}}`
/// whose non-zero exit code makes it an error.
fn codex_output(output: &Value) -> (String, bool) {
    let raw = output.as_str().unwrap_or_default();
    if let Ok(Value::Object(map)) = serde_json::from_str::<Value>(raw)
        && let Some(text) = map.get("output").and_then(Value::as_str)
    {
        let failed = map
            .get("metadata")
            .and_then(|metadata| metadata["exit_code"].as_i64())
            .is_some_and(|code| code != 0);
        return (text.to_owned(), failed);
    }
    (raw.to_owned(), false)
}

fn plan_of(steps: &Value, text_key: &str) -> Option<Vec<PlanStep>> {
    let steps: Vec<PlanStep> = steps
        .as_array()?
        .iter()
        .filter_map(|step| {
            let text = step[text_key].as_str()?.trim();
            (!text.is_empty()).then(|| PlanStep {
                text: text.to_owned(),
                status: match step["status"].as_str() {
                    Some("in_progress") => PlanStatus::InProgress,
                    Some("completed") => PlanStatus::Done,
                    _ => PlanStatus::Pending,
                },
            })
        })
        .collect();

//! plain data. Pure and tested headlessly; `shell/chat_view.rs` draws it.

use std::collections::HashSet;

use mkrew_core::thread::{PlanStatus, PlanStep, Subagent, ToolResult};

use crate::thread_view::{Page, PageItem, PageTurn};

/// A row that opens and closes: (turn key, item index, call index; 0 for thinking).
pub type RowKey = (u64, usize, usize);

#[derive(Debug, Clone, PartialEq, Eq)]
pub enum Row {
    /// Agent text: item `item` of the page turn.
    Text { item: usize },
    Thinking {
        key: RowKey,
        text: String,
        open: bool,
    },
    Tool {
        key: RowKey,
        name: String,
        target: String,
        input: String,
        result: Option<ToolResult>,
        open: bool,
    },
}

/// The mark before a plan step: an empty ring, a half ring, a check.
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum PlanMark {
    Todo,
    Doing,
    Done,
}

#[derive(Debug, Clone, PartialEq, Eq)]
pub struct PlanRow {
    pub text: String,
    pub mark: PlanMark,
}

#[derive(Debug, Clone, PartialEq, Eq)]
pub struct ChatTurn {
    /// `page.first_turn` + the turn's index: stable while the turn is kept.
    pub key: u64,
    pub prompt: String,
    pub rows: Vec<Row>,
    /// Only on the newest turn that has a plan.
    pub plan: Option<Vec<PlanRow>>,
}

/// One subagent in the tray.
#[derive(Debug, Clone, PartialEq, Eq)]
pub struct Chip {
    pub description: String,
    pub subagent_type: String,
    pub done: bool,
}

#[derive(Debug, Clone, PartialEq, Eq)]
pub struct QuestionCard {
    pub text: String,
    pub options: Vec<String>,
}

#[derive(Debug, Clone, Default, PartialEq, Eq)]
pub struct View {
    /// Older turns exist but are not kept ("Earlier turns: Open transcript").
    pub earlier: bool,
    pub turns: Vec<ChatTurn>,
    /// The last turn's subagents, only while one of them runs.
    pub tray: Vec<Chip>,
    /// The last turn's question, only while it has no result.
    pub question: Option<QuestionCard>,
}

/// The view of `page` with the rows in `open` expanded.
pub fn view(page: Option<&Page>, open: &HashSet<RowKey>) -> View {
    let Some(page) = page else {
        return View::default();
    };
    let plan_turn = page.turns.iter().rposition(|turn| turn.plan.is_some());
    let turns = page
        .turns
        .iter()
        .enumerate()
        .map(|(index, turn)| {
            let key = page.first_turn + index as u64;
            ChatTurn {
                key,
                prompt: turn.prompt.clone(),
                rows: rows(key, turn, open),
                plan: if plan_turn == Some(index) {
                    turn.plan.as_deref().map(plan_rows)
                } else {
                    None
                },
            }
        })
        .collect();
    let last = page.turns.last();
    View {
        earlier: page.truncated,
        turns,
        tray: last.map(|turn| tray(&turn.subagents)).unwrap_or_default(),
        question: last
            .and_then(|turn| turn.question.as_ref())
            .map(|question| QuestionCard {
                text: question.text.clone(),
                options: question.options.clone(),
            }),
    }
}

fn rows(turn_key: u64, turn: &PageTurn, open: &HashSet<RowKey>) -> Vec<Row> {
    let mut rows = Vec::new();
    for (item, entry) in turn.items.iter().enumerate() {
        match entry {
            PageItem::Text(_) => rows.push(Row::Text { item }),
            PageItem::Thinking(text) => {
                let key = (turn_key, item, 0);
                rows.push(Row::Thinking {
                    key,
                    text: text.clone(),
                    open: open.contains(&key),
                });
            }
            PageItem::Tools(calls) => {
                rows.extend(calls.iter().enumerate().map(|(call, c)| {
                    let key = (turn_key, item, call);
                    Row::Tool {
                        key,
                        name: c.name.clone(),
                        target: c.target.clone(),
                        input: c.input.clone(),
                        result: c.result.clone(),
                        open: open.contains(&key),
                    }
                }));
            }
        }
    }
    rows
}

fn plan_rows(steps: &[PlanStep]) -> Vec<PlanRow> {
    steps
        .iter()
        .map(|step| PlanRow {
            text: step.text.clone(),
            mark: match step.status {
                PlanStatus::Pending => PlanMark::Todo,
                PlanStatus::InProgress => PlanMark::Doing,
                PlanStatus::Done => PlanMark::Done,
            },
        })
        .collect()
}

/// Every subagent of the turn while at least one still runs; none once all are done.
fn tray(subagents: &[Subagent]) -> Vec<Chip> {
    if subagents.iter().all(|subagent| subagent.done) {
        return Vec::new();
    }
    subagents
        .iter()
        .map(|subagent| Chip {
            description: subagent.description.clone(),
            subagent_type: subagent.subagent_type.clone(),
            done: subagent.done,
        })
        .collect()
}

//! The transcripts the window reads (ADR 0057, ADR 0104) and the session panel's Thread
//! section. A 1 s poll per session runs only while the panel shows that agent session with a
//! native id, or (Task 7) a pane on screen is in Chat mode.

use mkrew_core::thread::CHAT_TURNS;
use mkrew_ui::chat;
use mkrew_ui::thread_view::{self, PageItem, ThreadFile};

use crate::*;

/// One session's transcript being read; shared by every consumer of that session.
pub(crate) struct ThreadRead {
    /// The session and native id being read; another pair starts a new read.
    pub(crate) key: (Ulid, String),
    /// The 1 s poll; dropping it stops reading. It ends by itself after the session exited
    /// (one last read).
    _poll: gpui::Task<()>,
    /// Built off the UI thread on each change; `None` until a read found turns.
    pub(crate) page: Option<Rc<thread_view::Page>>,
}

/// What the Thread section remembers about the shown session.
pub(crate) struct ThreadWatch {
    pub(crate) key: (Ulid, String),
    /// Expanded tool groups: (turn key = `page.first_turn` + turn index, item index).
    pub(crate) expanded: HashSet<(u64, usize)>,
    pub(crate) scroll: ScrollHandle,
}

/// The list shows its end: new turns keep it there.
pub(crate) fn at_bottom(scroll: &ScrollHandle) -> bool {
    -f32::from(scroll.offset().y) >= f32::from(scroll.max_offset().y) - 1.0
}

impl Shell {
    /// Starts, keeps or stops the readings to match what is shown (status tick): the panel's
    /// session, and the Chat panes. No work unless something shows a session with a native id.
    pub(crate) fn sync_thread(&mut self, cx: &mut Context<'_, Self>) {
        let session = self
            .panel_session()
            .and_then(|id| self.sidebar.sessions().iter().find(|s| s.id == id));
        let wanted = self.panel_shown() && self.panel_tab() == PanelTab::Session;
        let panel = inspector::wanted_thread(wanted, session);
        let keys = chat::wanted_reads(panel.clone(), Vec::new());
        let before = self.reads.len();
        self.reads.retain(|_, read| keys.contains(&read.key));
        let mut changed = self.reads.len() != before;
        for key in keys {
            if !self.reads.contains_key(&key.0) {
                let poll = self.poll_thread(key.clone(), cx);
                self.reads.insert(
                    key.0,
                    ThreadRead {
                        key,
                        _poll: poll,
                        page: None,
                    },
                );
                changed = true;
            }
        }
        match panel {
            None => changed |= self.thread.take().is_some(),
            Some(key) if self.thread.as_ref().is_some_and(|w| w.key == key) => {}
            Some(key) => {
                self.thread = Some(ThreadWatch {
                    key,
                    expanded: HashSet::new(),
                    scroll: ScrollHandle::new(),
                });
                changed = true;
            }
        }
        if changed {
            cx.notify();
        }
    }

    /// A new page of `session` was stored: a list that showed its end (or had nothing yet,
    /// `first`) keeps following it.
    fn page_arrived(&mut self, session: Ulid, first: bool) {
        if let Some(watch) = self.thread.as_mut().filter(|w| w.key.0 == session)
            && (first || at_bottom(&watch.scroll))
        {
            watch.scroll.scroll_to_bottom();
        }
    }

    fn poll_thread(&self, key: (Ulid, String), cx: &mut Context<'_, Self>) -> gpui::Task<()> {
        cx.spawn(async move |this, cx| {
            // One `session.transcript` read a second while shown; the daemon finds and reads the
            // file, so this works the same for a window on another computer (spec 2026-10-29 §5).
            // The connection is read each round: after a reconnect the watch carries on from
            // its offset, and while there is none it just waits.
            let mut file: Option<ThreadFile> = None;
            loop {
                let offset = file.as_ref().map_or(0, ThreadFile::offset);
                let connection = this.update(cx, |shell, _| shell.connection.clone());
                let Ok(connection) = connection else { return };
                let read = match connection {
                    Some(connection) => Some(
                        connection
                            .call::<SessionTranscript>(Request::SessionTranscript(
                                SessionTranscriptParams {
                                    session_id: key.0,
                                    offset,
                                },
                            ))
                            .await,
                    ),
                    None => None,
                };
                let mut more = false;
                let page = match read {
                    Some(Ok(read)) if read.found => {
                        more = !read.data.is_empty()
                            && read.start + (read.data.len() as u64) < read.len;
                        if file.is_none() {
                            file = ThreadFile::new(&UsageFormat::parse(&read.format), CHAT_TURNS)
                                .ok();
                        }
                        match file.take() {
                            Some(mut f) => {
                                let (back, page) = cx
                                    .background_executor()
                                    .spawn(async move {
                                        let changed = f.apply(read.start, &read.data);
                                        let page = changed.then(|| f.page());
                                        (f, page)
                                    })
                                    .await;
                                file = Some(back);
                                page
                            }
                            None => None,
                        }
                    }
                    // Not found yet (no usage profile, or the file is not written), or not
                    // connected: keep polling.
                    Some(Ok(_)) | None => None,
                    Some(Err(error)) => {
                        tracing::debug!("session.transcript failed: {error:#}");
                        None
                    }
                };
                let keep_going = this.update(cx, |shell, cx| {
                    let arrived = match (
                        page,
                        shell.reads.get_mut(&key.0).filter(|r| r.key == key),
                    ) {
                        (Some(page), Some(read)) => {
                            let first = read.page.is_none();
                            read.page = Some(Rc::new(page));
                            Some(first)
                        }
                        _ => None,
                    };
                    if let Some(first) = arrived {
                        shell.page_arrived(key.0, first);
                        cx.notify();
                    }
                    // The read above comes first: one last read after the exit.
                    shell.reads.get(&key.0).is_some_and(|r| r.key == key)
                        && !shell.is_exited(key.0)
                });
                if !keep_going.unwrap_or(false) {
                    return;
                }
                // A reply that did not reach the end of the file: read on at once.
                if !more {
                    cx.background_executor().timer(Duration::from_secs(1)).await;
                }
            }
        })
    }

    pub fn chat_of(&self, session: Ulid) -> Option<bool> {
        match self {
            Node::Pane { session: id, chat } => (*id == session).then_some(*chat).flatten(),
            Node::Split { children, .. } => {
                children.iter().find_map(|child| child.chat_of(session))
            }
        }
    }

    /// Saves `value` on the pane of `session`; false if it is not in the tree or already has it.
    pub fn set_chat(&mut self, session: Ulid, value: Option<bool>) -> bool {
        match self {
            Node::Pane { session: id, chat } if *id == session => {
                let changed = *chat != value;
                *chat = value;
                changed
            }
            Node::Pane { .. } => false,
            Node::Split { children, .. } => children
                .iter_mut()
                .any(|child| child.set_chat(session, value)),
        }
    }

                .filter(|_| self.view() == View::Terminals)
                .and_then(|id| self.tabs.get(&id)),

    pub(crate) fn chat_available(&self, info: &Session) -> bool {

    }

    /// `info`'s pane shows Chat: its saved mode (the layout leaf), else `[ui] chat_default`.
    pub(crate) fn chat_on(&self, info: &Session) -> bool {

/// A message: (turn key, item index); a selection lives inside one of them.
pub type MsgKey = (u64, usize);

/// A press at `at` in message `key`: a caret, Shift extends the selection of the same message,
/// a double click takes the word (as the Files preview does).
pub fn press(
    current: Option<(MsgKey, Selection)>,
    key: MsgKey,
    shown: &Shown,
    at: Point,
    extend: bool,
    clicks: usize,
) -> (MsgKey, Selection) {
    let selection = match current {
        _ if clicks == 2 => preview_select::word_at(shown, at),
        Some((was, selection)) if extend && was == key => Selection {
            head: at,
            ..selection
        },
        _ => Selection::caret(at),
    };
    (key, selection)
}

/// The text of message `key` in `page`; `None` when the page no longer has it as text.
pub fn text_of(page: &Page, key: MsgKey) -> Option<&Shown> {
    let index = usize::try_from(key.0.checked_sub(page.first_turn)?).ok()?;
    match page.turns.get(index)?.items.get(key.1)? {
        PageItem::Text(shown) => Some(shown),
        _ => None,
    }
}

    fn chat_press(
        &mut self,
        session: Ulid,
        key: chat::MsgKey,
        event: &MouseDownEvent,
        window: &mut Window,
        cx: &mut Context<'_, Self>,
    ) {
        cx.stop_propagation();

        let at = self
            .chats
            .get(&session)
            .and_then(|ui| ui.hits.borrow().get(&key).and_then(|hits| hits.hit(event.position)));

            .get(&session)
            .and_then(|read| read.page.clone())
            .and_then(|page| chat::text_of(&page, key).cloned());

                ui.selecting = None;
            }

        };

                at,
                event.modifiers.shift,
                event.click_count,
            ));
        }
        cx.notify();

```markdown
# 0104 - Chat view: a mode of the agent pane that reads the transcript

- Date: 2026-11-22
- Status: accepted (extends ADR 0057; amends SPEC sections 11, 13 and 20B)
- Milestone: none (human request 2026-11-22, spec `docs/superpowers/specs/2026-11-22-chat-view-design.md`)

## Context

Tern can show an agent as a chat: messages, tool calls with their arguments and results, a plan card, the agent's questions as cards, running subagents in a tray, and a composer at the bottom.
The user liked it.
Mkrew already parses Claude, Codex and omp transcripts into a read-only Thread section of the session panel (ADR 0057) and has a composer with a send queue, pickers and attachments (SPEC section 20B).

## Decision

- Chat is a mode of an agent pane, next to its terminal, not a new panel.
  A `Terminal | Chat` switch in the pane header (and `Ctrl+Alt+T`, palette "Toggle chat view") flips it.
- The data is the transcript, read by the same `ThreadReader` through `session.transcript`.
  The reader now also keeps tool call ids, arguments (4 KB) and results (8 KB, with an error mark), thinking (8 KB), the latest plan (Claude `TodoWrite`, Codex `update_plan`), a pending `AskUserQuestion`, and the turn's `Task` / `Agent` subagents.
  Its turn limit is an argument: 20 for the Thread section, 50 for Chat.
- One reader per session is shared by the panel and every pane in Chat mode (`Shell::reads`), so a transcript is never read twice.
  The shared reader keeps 50 turns and the Thread section shows the newest 20.
- The mode is saved per pane in the tab layout: the leaf gains `chat: true | false`; absent means not set, and then `[ui] chat_default` decides (default false, Terminal).
  The daemon stores layouts as opaque JSON, so no protocol or daemon change is needed and older layouts read unchanged.
- The terminal keeps running underneath: nothing about how the agent runs, resumes or reports state changes; its element is just not drawn.
- The composer is the existing one, docked and always shown in Chat.
  Enter sends and Shift+Enter adds a newline there; Esc moves the keys to the chat list.
  The Terminal-mode composer keeps Ctrl+Enter.
- A question is a card with the question and its options.
  Its "Answer in terminal" button switches the pane to Terminal.
- Chat is offered for agents with a readable transcript format: the shipped Claude, Codex and omp profiles, or any agent whose transcript the daemon located.

## Alternatives

- ACP (Agent Client Protocol) as the data source: rejected.
  It runs the agent headless, so the PTY, resume, hooks and screen patterns go, and it needs a Node adapter per agent; omp and Copilot have none.
- Answering a question or permission prompt from the card by typed keys: left out.
  It needs one fragile key map per agent TUI.
- A new panel instead of a pane mode: rejected.
  The pane already owns the session, its status and its composer.

## Consequences

- The UI depends on three more parts of the agents' file formats; a format change shows as a missing row, never as a broken pane.
- ADR 0057's exclusion of tool output and thinking is superseded in part: Chat shows them, the Thread section still does not.
- A text selection works inside one message, not across messages (ADR 0072 selects within one page).
- Every change re-parses the Markdown of at most 50 turns; cache by text if it ever shows.
```

## Spec gaps

Choices made where the spec and the code at HEAD disagree or are silent; the spec file is not edited.

1. **The Terminal composer is not an overlay.** The spec calls it "the overlay composer"; at HEAD `composer_panel` is docked under every pane and Esc only hides it (`crates/mkrew-ui/src/shell/composer.rs:35-57`, `pane_render.rs:592-594`). Chat reuses that panel, forces it shown, and changes only Enter, Esc and the hint line. Shift+Enter already yields a newline through `dialog_key` (`task_dialog.rs:82-83`).
2. **The leaf flag is `chat: Option<bool>`, not "true or absent".** With `chat_default = true` an absent flag must mean "the default", or a pane could never be switched back to Terminal. A switch writes an explicit `true` or `false`. With the default `false` this equals the spec (absent = Terminal, older layouts unchanged). Side effect: `chat_default = true` also applies to existing panes that have no saved mode, not only new ones.
3. **The Thread section no longer passes 20 to the reader.** The panel and Chat share one reader per session, which keeps 50 turns; the panel shows the newest 20 (`Page::newest`) and its "Earlier turns" line also shows when it hides kept turns. The reader argument exists and is used with 50 and 20 only in tests.
4. **"Profile has a readable format" cannot be asked of the UI.** `AgentProfileInfo` has no format field and the spec forbids a protocol change. Chat is offered for the shipped `claude`, `codex` and `omp` profile ids, or when the daemon already located the session's transcript (`Usages::get(id).transcript`). A copied profile therefore gets the switch only after its transcript exists.
5. **Selection is per message.** ADR 0072's `preview_select` addresses (block, piece, byte) of one `Shown` page, and a chat has one `Shown` per agent text. A selection and Ctrl+C work inside one message; drag stops extending when the pointer leaves it.
6. **The subagent "spinner" is the loading dots.** ADR 0086 forbids looping animation; the existing `loading_dots` on the status tick is used, and the tick redraws while a tray runs (`chat_animating`).
7. **`ToggleChat` must bypass the composer-focus gate.** In Chat the composer always has the keys, and `sessions.rs:286-294` and `detached_actions.rs:352-357` swallow every command while it does; both now let `ToggleChat` through. The spec is silent on this.
8. **Questions with several entries show the first.** `AskUserQuestion` may carry several questions; the card shows the first (`ponytail:` comment in the parser).
9. **`TodoWrite`, `update_plan`, `AskUserQuestion`, `Task` and `Agent` calls also stay as collapsed tool rows**, so their results and arguments remain inspectable; the cards are additional.
10. **Codex output and the tool schemas are inferred.** The repo has no real transcript for tool results, plans, questions or subagents; fixtures are hand-made from the documented shapes, and Codex errors are detected only from the wrapped `metadata.exit_code` form.
