**Interfaces:**
- Consumes: nothing from earlier tasks.
- Produces (used by Tasks 2 and 4):
  - `Turn { .., started_at: Option<i64>, ended_at: Option<i64>, output_tokens: u64, generation_ms: u64 }` (epoch ms).
  - `Item::Thinking { text: String, ms: Option<u64> }`.
  - `pub(crate) fn stamp_ms(stamp: &str) -> Option<i64>` in `thread.rs`.
  - `PageItem::Thinking { text: String, ms: Option<u64> }`, `PageTurn { .., started_at: Option<i64>, ended_at: Option<i64>, output_tokens: u64, generation_ms: u64 }`, `#[derive(Default)]` on `Page` and `PageTurn`.

Timing rules (from spec 3.1, made exact here):
- A line's time is its `timestamp` (ISO 8601). A Claude line with `isSidechain: true` has no time for this purpose (it is a subagent's line and takes no part in the turn).
- `started_at` and `ended_at` start as the prompt line's time; `ended_at` then keeps the newest time seen in the turn (a later line with an older time never lowers it).
- `generation_ms` adds, for every assistant line (Claude `assistant`; Codex `response_item` of an assistant `message`, `function_call`, `custom_tool_call` or `reasoning`; omp assistant `message`), the line's time minus the time of the line before it in the same turn, floored at 0. For Claude's one-block-per-line transcripts the sum over the lines of one message equals the last line's time minus the line before the message.
- `output_tokens` adds Claude `message.usage.output_tokens` (replacing what the same `message.id` counted before), Codex `token_count` `info.last_token_usage.output_tokens` (a `token_count` whose `total_token_usage.total_tokens` equals the previous one is a repeat and is skipped), omp `message.usage.output`.
- Thinking `ms` is the thinking line's time minus the previous line's (floored at 0); `None` when either has no time.

```rust
/// Longest model name the composer chip shows.
const MODEL_MAX: usize = 24;

/// A model name for a chip: the part after the last `/`, `claude-` and a trailing `-YYYYMMDD`
/// dropped, a dash between digits a dot and any other dash a space (`anthropic/claude-opus-5-5`
/// is `opus 5.5`), cut to [`MODEL_MAX`] characters with `…`.
pub fn short_model(name: &str) -> String {
    let base = name.rsplit('/').next().unwrap_or(name).trim();
    let base = base.strip_prefix("claude-").unwrap_or(base);
    let base = match base.rsplit_once('-') {
        Some((head, tail)) if tail.len() == 8 && tail.bytes().all(|b| b.is_ascii_digit()) => head,
        _ => base,
    };
    let chars: Vec<char> = base.chars().collect();
    let mut out = String::with_capacity(base.len());
    for (at, c) in chars.iter().enumerate() {
        if *c == '-' {
            let between_digits = at > 0
                && chars[at - 1].is_ascii_digit()
                && chars.get(at + 1).is_some_and(char::is_ascii_digit);
            out.push(if between_digits { '.' } else { ' ' });
        } else {
            out.push(*c);
        }
    }
    if out.chars().count() > MODEL_MAX {
        out = out.chars().take(MODEL_MAX - 1).collect::<String>() + "…";
    }
    out
}

/// A session title without the private-use glyph omp puts first (a Nerd Font icon) and
/// without edge blanks.
pub fn clean_title(raw: &str) -> String {
    let private = |c: char| {
        matches!(c, '\u{E000}'..='\u{F8FF}' | '\u{F0000}'..='\u{FFFFD}' | '\u{100000}'..='\u{10FFFD}')
    };
    raw.trim_start_matches(|c: char| private(c) || c.is_whitespace())
        .trim_end()
        .to_owned()
}
```

```rust
//! The newest recap omp wrote for a session (ADR 0105): `session_recaps` of
//! `<omp root>/history.db`, opened read-only. Anything unexpected (no file, no table, another
//! shape, a lock that does not clear in time) is no recap, never an error.

use std::path::Path;
use std::time::Duration;

use mkrew_core::profile::UsageFormat;
use mkrew_protocol::Recap;
use rusqlite::{Connection, OpenFlags, OptionalExtension};

/// How long a locked database is waited for.
const BUSY: Duration = Duration::from_millis(200);

/// The newest recap of the omp session `native` in `root`'s `history.db`; `None` for the other
/// agents' formats and for anything missing or unreadable (logged at `debug`).
// ponytail: one small query per poll of a shown omp session; cache by the file's mtime if it
// ever shows up in a profile.
pub fn latest(format: &UsageFormat, root: &Path, native: &str) -> Option<Recap> {
    if !matches!(format, UsageFormat::OmpJsonl) {
        return None;
    }
    match query(&root.join("history.db"), native) {
        Ok(recap) => recap,
        Err(error) => {
            tracing::debug!("omp recap not read: {error}");
            None
        }
    }
}

fn query(path: &Path, native: &str) -> rusqlite::Result<Option<Recap>> {
    if !path.is_file() {
        return Ok(None);
    }
    let db = Connection::open_with_flags(path, OpenFlags::SQLITE_OPEN_READ_ONLY)?;
    db.busy_timeout(BUSY)?;
    db.query_row(
        "SELECT recap, created_at FROM session_recaps WHERE session_id = ?1 \
         ORDER BY created_at DESC LIMIT 1",
        [native],
        |row| {
            Ok(Recap {
                text: row.get(0)?,
                at: row.get(1)?,
            })
        },
    )
    .optional()
}
```

```rust
/// An inline code span that looks like a file path (ADR 0105): the folder part, the file name
/// and an optional `:line[:col]` suffix.
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub struct PathPill<'a> {
    /// The path without the `:line` suffix (`dir` + `name`).
    pub path: &'a str,
    /// Up to and including the last `/` or `\`; empty for a bare file name.
    pub dir: &'a str,
    pub name: &'a str,
    /// `:12` or `:12:3`, as written; empty when there is none.
    pub suffix: &'a str,
    /// The first number of the suffix (1-based).
    pub line: Option<u32>,
}

/// `code` as a path pill, when it has no blanks and no `://` and either contains a `/` or `\`
/// (with a letter or digit in it) or ends in `.<ext>` of 1 to 8 letters or digits with at least
/// one letter (so `v1.2` and `1.5` are no paths). A trailing `:12` or `:12:3` is the line.
pub fn path_pill(code: &str) -> Option<PathPill<'_>> {
    if code.is_empty() || code.contains(char::is_whitespace) || code.contains("://") {
        return None;
    }
    let (mut path, mut line) = (code, None);
    for _ in 0..2 {
        match path.rsplit_once(':') {
            Some((head, digits))
                if !head.is_empty()
                    && !digits.is_empty()
                    && digits.bytes().all(|b| b.is_ascii_digit()) =>
            {
                line = digits.parse().ok();
                path = head;
            }
            _ => break,
        }
    }
    // A drive (`C:\`) is the only colon a path may keep.
    let body = match path.as_bytes() {
        [drive, b':', sep, ..] if drive.is_ascii_alphabetic() && matches!(sep, b'\\' | b'/') => {
            &path[2..]
        }
        _ => path,
    };
    if body.contains(':') {
        return None;
    }
    let shaped = if body.contains(['/', '\\']) {
        body.chars().any(char::is_alphanumeric)
    } else {
        body.rsplit_once('.').is_some_and(|(_, ext)| {
            (1..=8).contains(&ext.len())
                && ext.bytes().all(|b| b.is_ascii_alphanumeric())
                && ext.bytes().any(|b| b.is_ascii_alphabetic())
        })
    };
    let cut = path.rfind(['/', '\\']).map_or(0, |at| at + 1);
    let (dir, name) = path.split_at(cut);
    (shaped && !name.is_empty()).then_some(PathPill {
        path,
        dir,
        name,
        suffix: &code[path.len()..],
        line,
    })
}
```

```rust
/// every render, so it copies none of the transcript. `working`: the agent is working, so the
/// newest turn's last activity row says "Working…" and no recap shows; `recap`: omp's newest.
pub fn view<'a>(
    page: Option<&'a Page>,
    open: &HashSet<RowKey>,
    recap: Option<&'a Recap>,
    working: bool,
) -> View<'a> {
    let Some(page) = page else {
        return View::default();
    };
    let plan_turn = page.turns.iter().rposition(|turn| turn.plan.is_some());
    let newest = page.turns.len().checked_sub(1);
    let turns = page
        .turns
        .iter()
        .enumerate()
        .map(|(index, turn)| {
            let key = page.first_turn + index as u64;
            let is_newest = Some(index) == newest;
            let mut turn_rows = rows(key, turn, open, working && is_newest);
            if is_newest
                && let Some(recap) = recap.filter(|r| recap_shown(r, turn.started_at, working))
            {
                turn_rows.push(Row::Recap { text: &recap.text });
            }
            ChatTurn {
                key,
                prompt: &turn.prompt,
                rows: turn_rows,
                plan: if plan_turn == Some(index) {
                    turn.plan
                        .as_deref()
                        .filter(|steps| !steps.is_empty())
                        .map(plan_rows)
                } else {
                    None
                },
            }

        .collect();

        earlier: page.truncated,
        turns,
        tray: tray(page),

            .and_then(|turn| turn.question.as_ref())

/// A run of thinking and tool calls: becomes one [`Row::Activity`].
#[derive(Default)]
struct Group<'a> {
    first: Option<usize>,
    children: Vec<Child<'a>>,
    counts: Counts,
    thinking: bool,
    thinking_ms: Option<u64>,
}

impl<'a> Group<'a> {
    fn thinking(
        &mut self,
        turn_key: u64,
        item: usize,
        text: &'a str,
        ms: Option<u64>,
        open: &HashSet<RowKey>,
    ) {
        let key = (turn_key, item, 0);
        self.first.get_or_insert(item);
        self.thinking = true;
        if let Some(ms) = ms {
            self.thinking_ms = Some(self.thinking_ms.unwrap_or(0) + ms);

            key,
            text,
            ms,
            open: !text.is_empty() && open.contains(&key),
        });
    }

            self.counts.add(&call.name);
            self.children.push(Child::Tool {
                key,
                call,
                open: open.contains(&key),
            });
        }
    }

    /// Ends the run (nothing when it is empty). `running`: the turn runs and this row is its
    /// last.
    fn flush(
        &mut self,
        turn_key: u64,
        open: &HashSet<RowKey>,
        running: bool,
        rows: &mut Vec<Row<'a>>,
    ) {
        let group = std::mem::take(self);
        let Some(first) = group.first else {
            return;
        };
        let key = (turn_key, first, usize::MAX);
        let (thought, summary) = if running {
            (Some("Working…".to_owned()), String::new())
        } else {
            (
                thought_label(group.thinking, group.thinking_ms, &group.counts),
                group.counts.label(),
            )
        };
        rows.push(Row::Activity {
            key,
            thinking_ms: group.thinking_ms,
            counts: group.counts,
            thought,
            summary,
            children: group.children,
            open: open.contains(&key),
        });
    }
}

fn rows<'a>(
    turn_key: u64,
    turn: &'a PageTurn,
    open: &HashSet<RowKey>,
    running: bool,
) -> Vec<Row<'a>> {
    let mut rows = Vec::new();
    let mut group = Group::default();
    for (item, entry) in turn.items.iter().enumerate() {
        match entry {
            PageItem::Text(_) => {
                group.flush(turn_key, open, false, &mut rows);
                rows.push(Row::Text { item });
            }
            PageItem::Thinking { text, ms } => group.thinking(turn_key, item, text, *ms, open),
            PageItem::Tools(calls) => group.tools(turn_key, item, calls, open),
        }
    }
    group.flush(turn_key, open, running, &mut rows);
    rows
}
```

```rust
/// What of `want` fits in `room` px: chips drop from the right, in the order stats,
/// permission, effort, branch; the model chip and the fixed part (send, ✦, Prompts) stay.
pub fn fit_chips(want: Chips, room: f32) -> Chips {
    let width = |chips: &Chips| {
        theme::COMPOSER_FIXED_WIDTH
            + [
                (chips.model, theme::COMPOSER_CHIP_MODEL_WIDTH),
                (chips.effort, theme::COMPOSER_CHIP_EFFORT_WIDTH),
                (chips.permission, theme::COMPOSER_CHIP_PERMISSION_WIDTH),
                (chips.branch, theme::COMPOSER_CHIP_BRANCH_WIDTH),
                (chips.stats, theme::COMPOSER_CHIP_STATS_WIDTH),
            ]
            .into_iter()
            .filter(|(shown, _)| *shown)
            .map(|(_, width)| width)
            .sum::<f32>()
    };
    let drops: [fn(&mut Chips); 4] = [
        |chips| chips.stats = false,
        |chips| chips.permission = false,
        |chips| chips.effort = false,
        |chips| chips.branch = false,
    ];
    let mut chips = want;
    for drop in drops {
        if width(&chips) <= room {
            break;
        }
        drop(&mut chips);
    }
    chips
}

/// The Files path (`/` separators, relative to the workspace folder `base`) a path pill names,
/// or `None` when it leaves the workspace (an absolute path elsewhere, or any `..`). Pure: it
/// reads no disk, so it works for a machine window too. Folder and drive case do not matter.
pub fn files_path(base: &str, path: &str) -> Option<String> {
    let path = path.replace('\\', "/");
    let path = path.strip_prefix("./").unwrap_or(&path);
    let clean = |rest: &str| {
        (!rest.is_empty() && !rest.split('/').any(|part| part == ".."))
            .then(|| rest.to_owned())
    };
    let absolute = path.starts_with('/') || path.as_bytes().get(1) == Some(&b':');
    if !absolute {
        return clean(path);
    }
    let base = base.replace('\\', "/");
    let base = base.trim_end_matches('/');
    let inside = path
        .get(..base.len())
        .is_some_and(|head| head.eq_ignore_ascii_case(base));
    let rest = path.get(base.len()..).filter(|_| inside)?;
    clean(rest.strip_prefix('/')?)
}
```

```rust
/// The links of a piece of text: their byte ranges and destinations, whether it is on a page,
/// and an id for its clickable element (the address of its runs, stable while they live). In a
/// Chat message a code span that looks like a path is one too (`is_path`): it asks for
/// [`OpenPath`] of `path_of`'s session instead of [`OpenLink`].
struct Links {
    id: usize,
    ranges: Rc<[Range<usize>]>,
    dests: Rc<[String]>,
    is_path: Rc<[bool]>,
    on_page: bool,
    path_of: Option<Ulid>,
}

fn links(runs: &[Run], ctx: Ctx) -> Option<Links> {
    let path_of = match ctx.flavor {
        Flavor::Chat { session } => Some(session),
        Flavor::Doc => None,
    };
    let mut at = 0;
    let (mut ranges, mut dests, mut is_path) = (Vec::new(), Vec::new(), Vec::new());
    for run in runs {
        let range = at..at + run.text.len();
        at = range.end;
        match &run.link {
            Some(dest) => {
                ranges.push(range);
                dests.push(dest.clone());
                is_path.push(false);
            }
            None if path_of.is_some() && run.style.code && path_pill(&run.text).is_some() => {
                ranges.push(range);
                dests.push(run.text.clone());
                is_path.push(true);
            }
            None => {}
        }
    }
    (!ranges.is_empty()).then(|| Links {
        id: runs.as_ptr() as usize,
        ranges: ranges.into(),
        dests: dests.into(),
        is_path: is_path.into(),
        on_page: ctx.page,
        path_of,
    })
}

/// `styled` with its links clickable: a pointing hand over them, a click asks for [`OpenLink`]
/// (or [`OpenPath`] for a path pill). A press on a link is the link's alone: it starts no text
/// selection, block pick or caret move (gpui's `InteractiveText` lets it through).
fn linked(styled: StyledText, links: Option<Links>) -> AnyElement {
    let Some(Links {
        id,
        ranges,
        dests,
        is_path,
        on_page,
        path_of,
    }) = links
    else {
        return styled.into_any_element();
    };
    let (layout, pressed) = (styled.layout().clone(), Rc::clone(&ranges));
    // Registered by the parent, so it runs after the text noted where the press started.
    div()
        .on_mouse_down(MouseButton::Left, move |event, _, cx| {
            let on_link = (layout.index_for_position(event.position))
                .is_ok_and(|at| pressed.iter().any(|range| range.contains(&at)));
            if on_link {
                cx.stop_propagation();
            }
        })
        .child(InteractiveText::new(("md-link", id), styled).on_click(
            ranges.to_vec(),

                    return;

                match (path_of, is_path.get(index)) {

                        window.dispatch_action(Box::new(OpenPath { session, text: dest }), cx);
                    }
                    _ => window.dispatch_action(Box::new(OpenLink { dest, on_page }), cx),
                }
            },
        ))

}
```

```rust
    /// The model chip: the agent's own model picker opens in its terminal. The pane switches to
    /// Terminal and `/model` + Enter is sent (ADR 0105). A working agent queues it (SPEC §8).
    pub(crate) fn open_model_picker(
        &mut self,
        session: Ulid,
        window: &mut Window,
        cx: &mut Context<'_, Self>,
    ) {
        self.set_chat(session, false, window, cx);
        self.send_to_agent(session, "/model", window, cx);
    }

    /// `session.send` of `text` with Enter, outside the composer's draft; a failure is a toast.
    pub(crate) fn send_to_agent(
        &mut self,
        session: Ulid,
        text: &str,
        window: &mut Window,
        cx: &mut Context<'_, Self>,
    ) {
        let Some(connection) = self.connection.clone() else {
            return;
        };
        let sent = connection.request(Request::SessionSend(SessionSendParams {
            session_id: session,
            text: text.to_owned(),
            submit: true,
        }));
        cx.spawn_in(window, async move |this, cx| {
            let result = match sent.await {
                Ok(Outcome::Result(_)) => Ok(()),
                Ok(Outcome::Error(body)) => Err(body.message),
                Err(error) => Err(format!("{error:#}")),
            };
            if let Err(error) = result {
                tracing::warn!(%session, "session.send failed: {error}");
                let _ = this.update(cx, |shell, cx| {
                    shell.toast_error(format!("Cannot send: {error}"), cx);
                });
            }
        })
        .detach();
    }
```

Create `docs/decisions/0105-chat-look.md` (one sentence per line, no em dash):

```markdown
# 0105 - Chat look: Tern's drawing on Mkrew's transcript reader

- Date: 2026-11-23
- Status: accepted (amends ADR 0104 for the look; amends SPEC sections 7, 11 and 20B)
- Milestone: none (human request 2026-11-23, spec `docs/superpowers/specs/2026-11-23-chat-look-design.md`, plan `docs/superpowers/plans/2026-11-23-chat-look.md`)

## Context

ADR 0104 gave the agent pane a Chat mode and designed the data; it left the look to the Markdown renderer.
The page was a dense full-width list with one row per tool call, one row per thinking block and a flat composer box.
Tern shows the same transcripts as a calm centered column with status chips on the composer.
Checked on the user's machine on 2026-11-23: Tern runs omp in a normal PTY, omp tells Tern its session file with `ESC ] 1337 ; SetUserVar=omp_session_file=<base64 path> BEL` when `TERM_PROGRAM=tern`, and Tern reads that JSONL.
Tern's recap line is omp's idle recap, which omp stores in `~/.omp/agent/history.db`, table `session_recaps(session_id, cwd, created_at, recap)`.
So Tern and Mkrew have the same architecture; the gap is the drawing and a few fields Mkrew's reader dropped.

## Decision

- The look is Chat only: a centered column of 760 px (`CHAT_COLUMN_WIDTH`), a right-aligned prompt bubble, calm spacing, accent headings and bullets, and a floating composer card.
- Thinking and tool calls between two answer texts become one activity row ("Thought for 4s · 3 commands, 2 reads") that opens to the thinking text and the tool rows.
- The reader keeps per-turn start and end times, output tokens (Claude lines of one `message.id` count once), generation time, the time of each thinking block, Claude's redacted thinking (empty text), and a `SessionMeta` (model, effort, permission, title, context, window).
  The composer chips and the context meter come from them; the profile's `context_window` wins over the transcript's.
- The data path is unchanged: the UI's `ThreadReader` reads the transcript through `session.transcript`.
  No new reader, no RPC, no ACP.
- omp's recap is read by the daemon from `history.db`, opened read-only with a 200 ms busy timeout, and added to the `session.transcript` reply as `recap { text, at }` (protocol 57).
  A missing file, table or row, or any SQLite error, is no recap.
  The UI shows it after the last turn when it is not older than that turn's prompt and the agent is not working.
  A machine window gets the recap of that machine's daemon.
- OSC 1337 is not used.
  Mkrew already finds the transcript by the hook's native session id, and `TERM_PROGRAM=tern` would also switch on omp's Tern browser backend.
- The Markdown renderer gets a `Flavor` (`Doc` or `Chat`).
  Shared for every view: the code block card (language label, an always visible Copy button that says "Copied" for 1.5 s), path colors in inline code, accent bullet dots.
  Chat only: accent headings one step smaller without a rule, `space::M` between blocks, and clickable path pills.
- The model chip does not list models.
  A click switches the pane to Terminal and types `/model` + Enter with `session.send`, so the agent's own picker opens (like "Answer in terminal" in ADR 0104).
- The branch chip shows only when the session runs at the workspace root; a task worktree shows no branch chip.
- The composer collapses to a one-line pill while the pane has no keyboard and the draft, the queue and the error are empty.
- The `/` picker shows the current model next to `/model` and the context share next to `/compact`.

## Alternatives

- Setting `TERM_PROGRAM=tern` and reading OSC 1337: rejected, see above.
- A separate recap reader in the UI: rejected, the file is on the daemon's machine (SPEC section 3), so a remote window would read the wrong disk.
- A model list inside Mkrew: out of scope; the agents already have pickers.

## Consequences

- Protocol 57: a UI from before it shows a version mismatch with an old daemon; the user restarts the daemon.
- `mkrew-daemon` depends on `rusqlite` (same version and features as `mkrew-store`, no new package in the tree).
- Inline code is drawn as a text highlight with the raised background; GPUI text highlights have no corner radius or padding, so the "pill" has square corners.
- The reader keeps a map of Claude message ids per turn, bounded by the messages of one turn.
- Every poll of a shown omp session runs one small read-only query; cache by the file's mtime if it ever shows in a profile.
```

## Spec gaps

Where the spec and the code disagree, or the spec is silent, and the choice made here (evidence in the code at e11019f unless noted):

1. **Inline code "pill" with `radius::SMALL` and `space::XS` padding is not drawable.** Inline code is a `StyledText` highlight, and gpui-pre 0.3.7 `HighlightStyle` (`style.rs:580-601`) has only color, weight, style, background, underline, strikethrough and fade; the background is a square rectangle of the glyph run. Inline code already has the `surface_raised` background and the mono font (`preview.rs` `text()`); this plan keeps that and adds the path colors (folder muted, name semibold). Corner radius and padding would need per-word layout, which would also change `preview_select` pieces.
2. **`Flavor::Chat` carries the session** (`Flavor::Chat { session }`) because the path press must reach the right pane and the repo's idiom is an action (`OpenLink`, `CopyCode`) dispatched from the preview, which has no other way to know the pane.
3. **Path rule needs a letter in the extension.** The spec says "1 to 8 letters or digits", which makes `v1.2` and `1.5` paths; `terminal/links.rs::looks_like_path` already rejects them (it requires a letter), so the plan does the same.
4. **Activity counts: `shell_command` added** to commands.
