# Idle UI cost and omp 19 surfaces Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Stop one omp frame (and a hidden todo) from re-rendering the whole app, and let omp 19's new node kinds into the TSP mirror.

**Architecture:** Core `tsp::doc` accepts any node kind and `tsp::engine` warns once per surface. The UI routes `tsp.update` and the status tick's animation redraws to the `PaneView`s of the session instead of `Shell`, skips hidden nodes when deciding what animates, and skips row bookkeeping for frames that leave `main` alone.

**Tech Stack:** Rust, GPUI (`Entity::update`, `Context::notify`), serde_json.

**Spec:** `docs/superpowers/specs/2026-11-25-idle-perf-design.md`

## Global Constraints

- Protocol stays 63; no migration; no new crates; `Cargo.toml`/`Cargo.lock` untouched.

## Review Focus

- A `PaneView` notify must still redraw a pane whose session is on screen in a detached or second Space window: `notify_session_panes` walks every slot, not the current window's.
- The peek popover shows a notice for an omp session, never its surface (`peek::native_notice`): it must not get a `Shell` notify per frame, or an open peek brings the fan-out back.
- A frame that changes only the dock (composer text, hud, working row) must still redraw the pane even though `sync_rows` returns early.
- An omp 18 session (no new kinds) must behave exactly as before.
- A surface that fails ops, closes and opens again must warn again once.

/// A `button` that is `disabled` (true, or a reason string) or `busy` sends nothing (omp 19).
fn button_inert(node: &Node) -> bool {
    let disabled = match node.props.get("disabled") {
        Some(Value::Bool(on)) => *on,
        Some(Value::String(_)) => true,
        _ => false,
    };
    disabled || node.props.get("busy").and_then(Value::as_bool) == Some(true)
}

/// A frame of the shown surface that named no row and left `main`'s children as `known`:
/// the page list has nothing to splice, remeasure or regroup.
pub fn rows_unchanged(doc: &Document, known: &[String], dirty: &HashSet<String>) -> bool {
    dirty.is_empty() && doc.children("main").map(|n| n.id.as_str()).eq(known.iter().map(String::as_str))
}

- [ ] **Step 1: `notify_session_panes`** (pane_render.rs, after `render_pane`)

```rust
    /// Renders again every pane that draws `session`, in any window (ADR 0118): its window root
    /// renders with it, other panes and other windows reuse their last frame. For changes only
    /// the pane draws (an omp frame, a pane's own animation); anything else notifies `Shell`.
    pub(crate) fn notify_session_panes(&self, session: Ulid, cx: &mut Context<'_, Self>) {
        let views: Vec<_> = (self.pane_views.borrow().iter())
            .filter(|(slot, _)| slot.key.session() == Some(session))
            .map(|(_, view)| view.clone())
            .collect();
        for view in views {
            view.update(cx, |_, cx| cx.notify());
        }
    }
```
